# Code of Conduct

Ledgoryx welcomes constructive contributions from developers of all backgrounds.

## Expectations

Contributors should:
- Communicate respectfully.
- Focus criticism on technical decisions and behavior.
- Welcome good-faith questions and feedback.
- Respect differing experience levels.
- Avoid harassment, threats, discrimination, and personal attacks.
- Protect confidential information shared during security discussions.

## Enforcement

Maintainers may moderate discussions, close disruptive contributions, or restrict participation when necessary.

## Reporting

Report conduct concerns privately to the maintainers through an appropriate private GitHub communication channel.

Do not include personal or sensitive information in public issues.
